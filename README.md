# Web Development Internship - Task 4 🚀

Welcome to my fourth web development project, created during my internship at **ApexPlanet Software Pvt. Ltd.** ## 📝 About the Project

This project is an advanced, interactive Personal Portfolio built with a Single Page Application (SPA) approach. It demonstrates core software engineering concepts including state management using the browser's Local Storage, dynamic DOM manipulation, and complex JavaScript array methods.

## ✨ Key Features

* **Animated Dark/Glass UI:** Features floating background orbs with smooth CSS keyframe animations and a sleek Glassmorphism design.
* **SPA Navigation:** Smooth tab switching (About, Projects, Contact) without reloading the page, creating a seamless user experience.
* **Persistent Task Manager:** A functional To-Do list that saves tasks to the browser's `localStorage`, meaning data persists even if the page is refreshed or closed. Includes error-handling (try-catch) for corrupted data.
* **Dynamic Product Engine:** An e-commerce style product grid that allows users to filter items by category (Electronics, Fashion, Gaming) and sort them by price or rating dynamically.

## 🛠️ Technologies Used

* **HTML5:** Semantic layout and structure.
* **CSS3:** Custom variables, advanced keyframe animations, Grid/Flexbox layouts, and backdrop filters.
* **Vanilla JavaScript (ES6+):** * `localStorage` API for data persistence.
  * Array manipulation methods (`.filter()`, `.sort()`, `.map()`).
  * Dynamic DOM rendering.

## 🚀 How to Run

1. Clone or download this repository to your local machine.
2. Double-click the `task4.html` file to open it in any modern web browser.
3. Try adding tasks to the Task Manager and refreshing the page to see `localStorage` in action!
4. Test the filtering and sorting dropdowns in the Product Engine section.
